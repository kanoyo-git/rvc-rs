Help

Where are the voice models?

Put compact .pth voice models in assets/weights and open Models to refresh the list. Training checkpoints in logs can be exported from Models.

What does the retrieval index do?

Use the added .index file for the model and speaker. Set Index mix to zero for conversion without retrieval.

How do I train a voice?

Prepare the recordings, extract features and pitch, train, then build the index. The one-step button runs these stages with the settings in the training form.

Why does realtime audio break up?

The status shows processing time per block and audio dropouts. Increase the block duration if processing regularly takes longer than a block.
